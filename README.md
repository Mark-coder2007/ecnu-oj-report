# ecnu-oj-report

公开展示仓库：用于介绍这个项目做什么、边界是什么，以及完整实现大致长什么样。

这个公开仓库**不包含可直接运行的实现脚本**。完整实现、自动化脚本、依赖声明和可执行 skill 说明保存在单独的私有仓库中；这里保留的是：

- 项目介绍
- 文档说明
- 示例目录与示例配置结构

## 这是什么

`ecnu-oj-report` 这个项目的目标，是把一个 **ECNU Online Judge** 比赛整理成一份程序设计实践报告 `.docx`。

报告的核心结构是：

- 每题一张题面截图
- 每题一段对应的 C++ 源代码
- 全部内容按既有 Word 模板汇总输出

## 公开仓库为什么不放完整实现

这个项目涉及：

- 登录态持久化
- OJ 页面自动化访问
- 已 AC 代码导出
- 未 AC 题目的辅助求解与提交
- 本地模板化生成报告

这些内容在公开仓库中只做**文档级展示**，不直接提供可复用实现。这样这个仓库更适合：

- 展示项目思路
- 说明系统边界
- 给协作者或审阅者看目录结构和配置形状

## 自动化边界

这个项目不是“按一下按钮就稳定产出完整报告”的黑盒。

- 可脚本化部分：扫描 AC 状态、导出本人 AC 代码、批量截图、按模板拼装文档
- 需 agent 辅助部分：读未 AC 题面、模仿代码风格写解、本地编译、逐样例验证、决定是否提交

所以完整结果还依赖：

- `config.json`
- 登录态
- 题目状态数据
- 截图素材
- 已 AC 代码或后续补写代码

只给一个模板文档并不足以生成完整报告。
